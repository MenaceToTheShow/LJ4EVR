# Spikes (design-phase evidence)

Three throwaway programs built during the design workflow (2026-10-21) to settle
the UI toolkit question before W0; the judge verdicts and decisions D1-D16 cite
them. They are kept as evidence and are **not built by the root CMake**: each has
its own `CMakeLists.txt` and README with the exact commands.

| Dir | Proves |
|---|---|
| `a-fidelity/` | TSEQUENCEFORM drawn Windows-classic on SDL3 with an own rasteriser; the 13 px MS Sans Serif metrics and the six AutoSize widths |
| `b-lazy/` | the minimal-code route (what was rejected and why) |
| `c-engineering/` | the MSVC 19.44 + SDL3 build recipe (PCH off, UseMultiToolTask), Ninja vs VS generators, backbuffer blit |

Committed: sources, headers, CMakeLists, READMEs, scripts, logs and PNG
screenshots. Not committed: `build*/` directories and every `.bmp` surface dump
(`.gitignore`); `spikes/a-fidelity/surface.bmp` is regenerated by
`spike_sequence.exe --save surface.bmp` when the W0 golden comparison needs it.
