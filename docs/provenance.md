# Provenance

Where every byte in this repository that is not our source code came from, and
under what terms it is here (ME-36, ME-37; decisions D2 and D13 in the design).
The rule behind the table: **nothing from Martin's installer, help or manuals is
committed.** The `reference/` tree on the developer PC (the 2.209 installer, the
CHM help and its images, the manuals, the fixture files) is gitignored and is read
by `tools/` as data only. What the tools carry out of it is fact: captions, menu
trees, geometry, hints, tab orders, DMX tables and message texts, reproduced
verbatim (Martin's typos included), never a bitmap, icon, RTF, help sentence or
profile file.
