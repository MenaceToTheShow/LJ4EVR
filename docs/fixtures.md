# Fixture library (fixlib)

Design 6, verdicts ME-8, ME-25, ME-26, ME-27, LORD_FIXTURES-9/-10/-11. What the fixlib
layer ships in W1, where each number comes from, and how the tools keep it honest.

## Identity: the 201 exe rows

`src/fixlib/lj_exe_profiles.c` is `reference/installer/exe_profile_table.txt` committed
verbatim (ids 0-200, tag, manufacturer, name, mode, notes file), generated by
`tools/exe_profiles_check.py` with a sha256 banner. The id is LJ2's own `Config.dat`
type code, so `profile_id` in a saved show never depends on generation order. Row 0 is
`None`, row 32 is the exe's empty slot (notes `xxx`), and the leading space of
` 1 Channel` is kept because that is what the tree shows (15/10 s1). Each row carries a
`binding`: `LJ_BIND_HAND` (tier 1 hand file), `LJ_BIND_QXF` (tier 2 QLC+ conversion) or
`LJ_BIND_NONE` (greyed, hint `Not available in LJ4EVR`, cannot be added).

    python -I tools/exe_profiles_check.py           # rewrite the table (needs reference/)
    python -I tools/exe_profiles_check.py --check   # CI: ids 0..200, binding column vs hand/*.c + qxf_map.tsv,
                                                    # every W1 tier-1 id has a hand file; diff vs regeneration when reference/ exists

API (`fixlib/lj_profile.h`): `lj_fixlib_by_id(id)` returns the hand profile, else the
QLC+ profile (windows derived at first use), else NULL; `lj_fixlib_count()` = 201 + the
extras; `lj_fixlib_row(i)` = the exe rows for i < 201, then the extra rows;
`lj_profile_window(p, kind)` = the control window table or NULL (toolbar button disabled).

### Fixture Configuration tree order

The tree is those rows grouped `manufacturer > name > mode` exactly as LJ2 shows them
(13 s2.7-2.8, CHM thefixtureinfotab.htm): manufacturers alphabetically (Clay Paky,
Generic, Jem, Martin, Other, User Definable as in IMG fixtureconfiguration.jpg), a name
with one mode is a leaf, a name with several modes is a folder of mode leaves (`MAC 500 >
Mode 2/4`, `SCRL, Mode 2/4`). Extras (ids >= 1000) appear under their own manufacturer
only with `[FIXTURES] ShowExtraProfiles=1` in `Main.Ini` (PROPOSAL; LJ2 had none).
User `.GS2` profiles list under `User Definable` from `UserFixtureDef\` (W3).

Rules the hand files follow:

- Captions are the exe literals (`Shutter Closed`, `Pulse Off`, `Fixed Goboweel Scroll`
  with Martin's typo, `NOTE ! Lamp Off must be held for at least 5 seconds`).
- Every button carries `value` beside its `lo..hi` Martin range; `value` = the low end of
  the range until F47 is verified, so the rig edits one number.
- `LJ_W_ROTATION` / `LJ_W_WHEELSCROLL` buttons are `{CW lo..hi}, {CCW lo..hi}, {Stop value}`
  and the bar maps speed inside the pressed range (LORD_FIXTURES-10). `LJ_W_MODEPAIR`
  names its two sub-rows in `caption` / `caption2`. `LJ_W_RADIOGROUP_FADER` lists the
  radio captions in `items` and the value each radio writes in `buttons`; the `Speed`
  radio takes the fader over `lo..hi`, `reverse = 1` when the fader shows `Slw` at the
  bottom. `LJ_W_PALETTE.lo` is the index into `lj_profile.palette[]`.
- One `LJ_W_FADEBTN` row per channel group with `rows` = the span it covers (the MAC 500
  Snap button spans Shutter and Strobe, both channel 1); Levels tables carry no FADEBTN
  rows, each fader owns its O/S/F button below it.
- `states_allowed` (ME-27): `LJ_STATES_ALL` by default; Lamp Control rows, the Extended
  window's Fixture Reset and every static special are `LJ_STATES_OFF_SNAP`; `SWITCH`
  class rows are `LJ_STATES_OFF_SNAP` (ME-25: on = 255, off = 0, never Fade).
- The MAC 500 / 918 have eight windows: Intensity, Movement 16 Bit, Colors, Gobos, Beam,
  Effects, Lamp Control, Extended (15/01 s3: "No Smoke, no Levels grid"); Fixture
  toolbar button 7 (the Levels icon) opens Extended for them. Dimmers, switches, smoke
  and hazer have only Levels; the RGB pack has `LJ_CTL_RGBPACK` (control lands in W2).
- Palettes: gel names are the exe colour-table facts, RGB values are ours; gobo slots name
  our schematic tiles (`art/glyphs/gobo_*.txt`) after the manual's default layout and are
  PROPOSAL per slot (LORD_FIXTURES-9). Rotating gobos carry `Def` = index value and `Rot`
  (type code 6) = continuous-rotation value.
- `default_dmx` stays 0 everywhere: LJ assumes 0 unless the profile states a default,
  and no written source gives the W1 built-ins any (15/00 s5).

## Tier 2: QLC+ conversions (`tools/qxf2c.py`)

`third_party/qlcplus-fixtures/` holds the 73 `Martin-*.qxf` of the QLC+ repository at
the commit recorded in `SOURCE` (Apache-2.0, `LICENSE` + `NOTICE` beside them). They are
read offline only. `tools/qxf_map.tsv` (hand-maintained, `file<TAB>mode<TAB>id`) says
which modes become profiles and which exe row each binds to; an id >= 1000 is an extra.
A hand file for the same id wins in `lj_fixlib_by_id` (id 12 is mapped on purpose so the
precedence is exercised; the QLC+ MAC500 data is never what the MAC 500 shows). Modes
with more than 32 channels (`LJ_PROFILE_CH`) cannot be mapped.

    python -I tools/qxf2c.py             # write src/fixlib/lj_profiles_gen.c + tools/qxf2c_overflow.txt
    python -I tools/qxf2c.py --check     # CI generate-check: drift, bad map lines (unknown id, duplicate id, missing file/mode, > 32 ch); prints the overflow list
    python -I tools/qxf2c.py --selftest  # determinism, the MAC500 DMX4 facts, a synthetic QXF (non-adjacent pan/tilt LSBs, reversed focus, NoFunction)

Output: one `static lj_profile lj_qxf_<id>` per mapped mode with a provenance comment
(file, mode, QLC+ commit, Apache-2.0, `modified: converted`, author), identity = the exe
row's triple, CP1252 strings as octal escapes, deterministic order (by id). The windows
are not generated: `lj_layout_derive()` builds them at first use (below).

### Group + Preset -> class / dyn / palette (ME-26)

| QLC+ channel | `channel_class` | dyn / field | palette |
|---|---|---|---|
| Preset `IntensityDimmer`, `IntensityMasterDimmer`, Group `Intensity` without preset (first one) | `INTENSITY` | `intensity` 0..255 | - |
| any other Group `Intensity` channel, `IntensityWhite/Amber/Lime/UV/...` | `LEVEL` | visible Levels fader | - |
| `IntensityRed/Green/Blue` | `LEVEL` | `cmy[0..2]`, `rgb_on = 1` | - |
| `IntensityCyan/Magenta/Yellow` | `LEVEL` | `cmy[0..2]`, `cmy_on = 1` | - |
| `IntensityHue/Saturation/Value` | `LEVEL` | `hsv[0..2] = 1` | - |
| `PositionPan` / `PositionTilt`, Group `Pan` / `Tilt` Byte 0 | `PAN` / `TILT` | `pan_ofs`, `tilt_ofs`; both fine channels present -> `pt16`, else `pt8`; a fine channel not at MSB + 1 -> `pt_patch_on` + `pt_patch` | - |
| `PositionPanFine` / `TiltFine`, Byte 1 | `PAN` / `TILT` | the LSB of the pair | - |
| Group `Shutter` with `ShutterClose` + `ShutterOpen` capabilities (first such) | `SHUTTER` | `shutter` {closed value, open value}, `blackout` = closed value; first `Strobe*` capability -> `strobe` {min, max}, `strobe_off` = open value | - |
| Group `Shutter` otherwise | `STROBE` | `strobe` from the first `Strobe*` capability | - |
| `ShutterIris*`, Group `Beam` with "iris" in the name | `BEAM` | `iris` | - |
| `BeamFocus*`, "focus" in the name | `BEAM` | `focus` (`FarNear` = 255..0, reversed) | - |
| `BeamZoom*`, "zoom" in the name | `BEAM` | `zoom` (`BigSmall` reversed) | - |
| other Group `Beam` | `BEAM` | `frost` when the name says frost, else `beam[0..1]` | - |
| Group `Colour`, `Color*` presets | `COLOR` | `color[0..3]` in order | `palette[0..1]` for the first two wheels |
| Group `Gobo`, `Gobo*` presets | `GOBO` | `gobo[0..3]` (`GoboIndex*` lands in the next free slot without a palette) | `palette[2..3]` for the first two wheels |
| Group `Effect` / `Prism`, `Prism*` presets | `EFFECT` | `effects[0..3]` | `palette[4..5]` for the first two |
| Group `Speed`, `Speed*` presets | `SPEED` | invisible, no window (Extended radios are built-in only) | - |
| Group `Maintenance` | `SPECIAL` | visible Levels fader | - |
| `NoFunction`, Group `Nothing` | `NONE` | `level_invisible = level_disabled = 1` (unpatched, LORD_FIXTURES-11) | - |
| Byte 1 channel of a non-pan/tilt group | same as its MSB | `pair_lsb[msb] = 1 + ofs` (LJ_PAIR16_NON_PT_AS_ONE) | - |
| capability `ResetAll` / `LampOn` / `LampOff` on any channel | - | `reset` / `lamp_on` / `lamp_off` static {offset, Min} | - |

Palette entries: one per capability whose preset is `ColorMacro`, `ColorDoubleMacro`,
`ColorWheelIndex`, `GoboMacro`, `PrismEffectOn/Off`, `GenericPicture`, or an untyped
capability whose text is not a motion word (rotate, CW, CCW, shake, random, chase,
scroll, spin, strobe, pulse, reset, lamp, macro, stop); `v[0]` = the capability `Min`,
`rgb` = `Res1` `#rrggbb` as `0x00RRGGBB`, type `Def`. **Overflow rule: the first 20
candidates are kept** (`LJ_PAL_ENTRIES`); every wheel with more is one line of
`tools/qxf2c_overflow.txt` (`file  mode  id  channel  count`), committed, diffed by
`--check` and printed by the CI `generate-check` job. Channel names become `level_caption`
(5 bytes) and dyn names (8 bytes), CP1252.

Known tier-2 limits (by design, not bugs): old untyped files (Roboscan 812/218) have no
`ShutterOpen` preset and come out as `STROBE` without a shutter button; QLC+ speed and
maintenance channels get no Extended window; QLC+ has no notion of LJ's wheel-rotation
or shake sub-ranges, so tier-2 colour/gobo rows are scroll + palette only.

## Derived windows: `lj_layout_derive()` (`src/fixlib/lj_layout.c`)

For `.GS2` and QLC+-derived profiles, mirroring the help's Generic Fixture 2 derivation
("Only controls for the enabled functions will be visible", note 02 s5): shutter / strobe
/ intensity -> Intensity; `pt16` / `pt8` -> Movement (plus `misc_move`); each enabled
`color[k]` -> a Colors scroll row plus a palette row for k < 2; CMY / RGB -> three bars;
`gobo[0..1]` -> scroll + palette, `gobo[2..3]` -> index bars; iris / focus / zoom / frost /
beam -> Beam bars; `effects[0..1]` -> scroll + palette, `effects[2..3]` -> bars; enabled
visible levels -> Levels faders (caption `level_caption` or `CHn`); enabled specials ->
the Levels window's Special menu (`LJ_W_SPECIAL_GROUP`, one button per defined offset,
`OFF|SNAP`); lamp on / off -> Lamp Control (`OFF|SNAP`). A dyn with `min > max` gives
`reverse = 1` with `lo`/`hi` ordered. Consecutive rows on one channel share one fade
button. Rows are allocated once per profile and kept for the process lifetime. The full
rule table is the comment at the top of `lj_layout.c`; `test_fixlib_profiles` runs it
over a synthetic `.GS2`-shaped profile and over every QLC+ profile.

## W0-gs2-266C

The 17 unlisted bytes at `.GS2` offset 0x266C are carried by the W3 `lj_gs2_parse` as
`reserved_266C` (raw 17 bytes inside `gs2_raw`) and written back untouched; the note is in
`docs/w1-contracts.md` and on `lj_gs2.h`. Nothing in W1 decodes them; `lj_gs2_parse`,
`lj_gs2_write` and `lj_udf_import` are W1 stubs returning -1.

What the W2 tables add to the W1 rules:

- Studio Washes: the dimmer wheel (ch 8) is the primary `Intensity` bar and class
  `INTENSITY`; the blades (ch 2) are `Int (Sec)`, `default_dmx` 255 (NOTES), class `LEVEL`
  without Extended GM so the master does not apply twice (PROPOSAL rig item).
- 16-bit index pairs that are not pan/tilt carry `pair_lsb` (Krypton / Entour ch 5-6, MAC
  2000 Profile ch 9-10 and 12-13, Performance ch 8-9); pan/tilt pairs stay `pt16` + `pan_ofs`.
- The Roboscan 812 has no Intensity window: blackout and Grand Master 0 write the blackout
  gobo (ch 3 = 255, `bo_at_gm0`); its Lamp window is `TLampControl_DO` (`Strike Lamp` only).
  The 518 Lamp window is `DOOF` (`Lamp On`, `Lamp Off`, `Fan Lo`) on the strobe channel.
- Extended windows pick the exe radio variant that matches the speed channel's ranges
  (15/00 s4); the Performance pan/tilt channel matches the `Fan regulated | Fan full` variant.
- No source gives the Mac 250 Laser prototype or the three DMX-interface entries a channel
  map: they are Levels-only profiles with PROPOSAL footprints until the rig or the Martin
  DMX Interface manual says otherwise.
- Not exposed in W2 (W4 sweep): the random-CMY limit specials (`Norm Off Full Min Max`), the
  518's per-gobo rotation speed bar, the 250+'s indexed gobo type, the Performance's
  `Synchronize Shapers` toggle.
