# DMX-in

DMX-in takes one 512-slot universe from the network and feeds it to the Global Patch (the S1 source, design 3.5) and to
the DMX-in functions of note 05 s3.2. Code: `src/io/lj_dmxin.c` (receiver, tables, functions), `src/windows/lj_dmx_in.c`
(the five windows, the Hardware Setup row, the function rows), `app/lj_app_io.c` (the per-pass glue). Track dmxin, W5.

## Turning it on

Setup > Hardware Setup, the "Enable DMX in" box, the input universe beside it and the protocol (sACN or Art-Net). It is
off on a fresh installation. With sACN the program binds UDP `0.0.0.0:5568` (shared with other receivers), joins the
multicast group of that universe on the network interface chosen for output, and also takes unicast. With Art-Net the
input rides the Art-Net socket on port 6454 that the output side owns (the universe box is then the 15-bit Port-Address).
An sACN input universe equal to one of our own output universes is refused, and packets carrying our own CID are ignored.
Settings: `Hardware.Ini [DMXIN]` (`Enabled Source Universe Nic Loss FunctionsOff`).

## Receiver rules (sACN, E1.31-2018)

A data packet is discarded when the preamble, post-amble, ACN packet identifier, root vector (only 0x4; the extended
0x8 is not data), framing vector, DMP vector, address and data type, first property address or address increment is
wrong; when the property value count is outside 1..513 or claims more bytes than arrived; when the three PDU lengths
disagree with the count; when the universe is outside 1..63999 or the priority above 200; when the START code is not
0x00 (0xDD per-slot priority is ignored). The universe is read from the packet. Preview_Data packets are ignored. Per
source (CID), a packet whose sequence number B is behind the last one A by a signed 8-bit difference in (-20, 0] is
discarded. A source is dropped after 2.5 s without a packet or at its first Stream_Terminated packet. A packet with
fewer than 512 slots leaves the rest at 0. Source names are read as at most 63 bytes and converted to CP1252.

## Merge (the E1.31 6.2.3.4-5 declaration)

The highest priority among the live sources wins. Sources at that same priority are merged highest-takes-precedence per
slot. At most 4 sources are tracked at once (PROPOSAL rig W5-DMXIN-2); a fifth is ignored and counted as "sources
exceeded". Art-Net senders join the same merge at priority 100. When every source is lost the input frame holds its last
values (the default, `Loss=0`) or goes to zeros (`Loss=1`), PROPOSAL rig W5-DMXIN-3.

## Value tables (.vtr)

A table maps an input value 0..255 to an output value; channels with a table are translated before the Global Patch and
the functions see them. Tables are ASCII CRLF files `<Type>_<Name>_<ID>.vtr` in `<userdata>/User/ValueTables/`: a header
line `// LightJockey DMX value translation file`, `ID=` a GUID, `TYPE=`, `NAME=`, `PURPOSE=`, then `n=m` lines; a missing
entry maps 1:1. They belong to the installation and are not in library backups. A file is refused when it is over 16 KB,
has a line over 256 bytes, a number outside 0..255 or out of range, a duplicate entry, an ID that is not a GUID or no
TYPE / NAME. Refused files are listed in the "Error importing translation tables" window when the translation window
opens. The eight SYSTEM tables (Linear, Linear inverted, Off/on with threshold, Off/On, On/Off, Sine, Sine inverted, Sqrt)
are built into the program, regenerated by `tools/gen_vectors.py --vtr` from their mappings; their PURPOSE texts are ours.
A table assigned to a channel is copied into the assignment; "Update translations" copies it again from the folder by ID.

## The Dmx In window

Opened from the cue-list toolbar DMX In button, or by double-clicking the DMX In source field of the Global Patch. The top
line shows the incoming channel count and the update rate. Select a channel and a function and press Assign Function;
Clear Assigned removes it. **Nothing takes effect until Save**: Save writes `<library>/DmxIn/DmxIn.dat` and makes it the
live map. Options > Disable DMX-in functions (and the three "DMXin Functions" hotkeys) stop the functions; the Global
Patch overrides keep working. Preferences > Cue Latch > Clear Cue on Cue# 0.

Function rules (note 05 s3.2): a level above 127 is "on"; edge functions fire on the move from 127 or below to 128 or
above; Cuelist Go (Alt) fires on 0-127 -> 128-255, 128-191 -> 192-255 and 192-255 -> 128-191; Static n, Latch is on at
50 % (128) and above; the Binary Cue Value bits (1..128 and 512) add up to a cue number that loads only while Latch Cue is
above 127; Overwrite Enable gates every Global Patch DMX-in source except a channel switched to Ignore DMX In Enable
(Global Patch popup > DMX in Enable Switch, W6), and is on while it is not assigned; Cue Time and
Sequence Time follow the Cue Time Control preference (always, or on a change of 1 / 2 / 3 steps).
